# Contribution boundary fallback

**Fallback policy `[owner: copilot-extensions-maintainer]`:** copilot-extensions accepts only general-purpose, organization-neutral capabilities; personal needs belong in the adopter's private control repo and organization-specific work in its internal marketplace. Invoke the `contributing-to-copilot-extensions` skill for explicitly assigned source work. Enabling this maintainer package is not an assignment, publication approval or a grant to repair this suite during another product's task. Automatic maintenance requires an operator charter naming this source responsibility and its destinations. Local installation repair remains separate from source contributions.
For an explicitly adopted suite infrastructure-maintainer source-repair extension, that skill owns the diagnosis-through-consumer-verification loop.
