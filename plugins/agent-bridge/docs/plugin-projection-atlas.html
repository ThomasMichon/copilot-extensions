Agent Bridge / Plugin delivery

Which worktree supplies the child's plugins?

Resolve the actual execution checkout first. Its native marketplace declarations and explicit choices remain authoritative. Project only the eligible controller additions, preserve their source kinds, then register and verify the child's effective selection.

Same repository is not the same worktree. When worktree A drives worktree B, B's ./.ai means B's marketplace and B's revision. Neither A nor a repository anchor silently supplies B's own plugins.

Same repository, independent marketplace revisions

This diagram assumes B declares the marketplace locally (for example, ./.ai). An operator-authored external target-local source remains an explicit choice. Same-repository identity does not authorize rewriting every external path.

Selection, projection and launch are distinct

A connection, process ID, copied directory or settings file is not readiness. Failure or cancellation must not deliver the task with an incomplete selection. This flow specifies required outputs; the matrix identifies launch adapters whose integration is still open.

Evidence and current limits

The same-repository regression uses actual linked Git worktrees with different committed payloads. It exercises ordinary ACP launch composition, the CLI acquisition preparation request, copy-mode preparation and an independent settings resolver process. It also checks repeated child edits, explicit disables, missing-payload refusal, unchanged global preferences and no source-catalog writes.

The static SSH controls additionally stream the real shared engine through an opt-in SSH profile to an isolated receiver checkout. They exercise Windows shell framing, bounded descendant cleanup and cancellation quiescence without installing a Bridge or starting Copilot. This same-filesystem SSH control is not cross-machine native-skill proof.

A retained POSIX test venue additionally reproduces the original early-exit descendant leak and confirms cleanup on success, error, deadline and lost supervisor. This qualifies process cleanup, not an executing agent's skill set.

Privileged source controls additionally round-trip the optional context through both actual ACP SDK connections and prepare a real allocated child checkout with native-source precedence. They cover old-peer refusal, request ownership and non-recreating resume, with elevation simulated rather than a live admin token.

Those checks do not assert a new live Copilot run, live privileged acceptance, live trusted container acceptance, release promotion or installed-runtime rollout. Existing Codespace selected-skill evidence likewise does not close the full simultaneous target-user and staged-repository capability matrix.
