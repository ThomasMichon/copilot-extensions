# Containers command-admission controls

The [suite testing guide](../../../TESTING.md) owns runner and isolation
mechanics. `test_managed_command_gate.py` runs actual Bash and PowerShell gates
with real prepared UV, a 3.10.20 application and an independent 3.11.18 helper.
Eighteen raw/materialized controls per native shell retain current/LKG/newest
and namespaced selection, readiness and invocation metadata, Legacy argument
forwarding, stdin, both streams, exit status, runtime/state roots and inherited
descriptors. Successful paths run twice with poisoned ambient Python/selectors
and shadow commands, while payload and slot bytes remain unchanged.

Missing UV/provider/capture refuses before application entry or provisioning.
Those controls use the existing explicit helper selector to isolate application
admission. Test-only observation counts native UV work without replacing UV:
one application lookup per Bash call; PowerShell additionally performs the
existing helper version check and helper lookup.

The path-gated Ubuntu/macOS/Windows jobs require every applicable case and report
without skips within eight-minute deadlines. Retained publication-policy,
evaluator/transport and readiness-import controls run separately.
Fresh-provision controls restore prepared UV after their setup-only refusal
stub, then require global command admission for both legacy and selected-cell
bindings. Namespaced
installation management retains Bash 4.4+ on macOS, selected after the command
packet runs under system Bash; canonical management under Bash 3.2 is not
qualified by the synthetic context decisions.

Inert modules and context decisions perform no Docker, Podman, backend, relay,
credential or service operations. This is not installed-host adoption, complete
command-latency measurement or qualification of other child producers.

The retained macOS global-stamp path also qualifies the existing Python fallback
transaction check on both Containers and Machines. It compares native
`os.fstat(8)` with the no-follow named lock rather than Darwin's descriptor
filesystem metadata. Six POSIX controls retain successful admission and
replaced-file/symlink refusal; native-flock behavior, persistent inode,
legacy-receipt refusal and close-only lock lifetime are unchanged.
