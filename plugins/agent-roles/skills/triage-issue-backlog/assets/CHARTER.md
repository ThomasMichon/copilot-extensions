## Activation walkthrough

Record actual outcomes/unknowns; [synthetic scenarios](scenarios.json) are not
live provider, runtime, deployment or model-admission proof.

- [ ] Casual target plus filter resolves without widening its scope.
- [ ] Harness and knowledge addenda are scoped, durable and non-authorizing.
- [ ] Missing optional owners/addenda do not trigger an installation ceremony.
- [ ] Read-only ADO/GitHub access never becomes write authority.
- [ ] Complete census, current ownership/freshness and capacity precede assignment.
- [ ] Held items do not starve eligible source caching.
- [ ] Partial worker evidence cannot acquire a completion marker.
- [ ] Source/fixtures/merge/release/install/live proof remain distinct.
- [ ] One publisher, useful owned summary and unknown-effect reconciliation.
- [ ] No unchanged/due-only research loop or duplicate status posting.
- [ ] Source error and missing history hold rather than reset admission.
- [ ] Native completion/wake handling retains actual handles and no worker polls.
- [ ] Stop/transfer settles or names every live obligation; no automatic registrar takeover.
