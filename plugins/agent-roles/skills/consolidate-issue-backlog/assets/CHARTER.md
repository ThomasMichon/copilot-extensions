## Activation and closeout checks

- [ ] Explicit target, finite denominator and inflow rule are resolved.
- [ ] Original authority, required guidance, identity and current holds are known.
- [ ] Complete census and provenance precede text; unknown use remains unknown.
- [ ] No prior refusal, cap or owner condition is reset by reactivation.
- [ ] Cohorts distinguish whole overlap from themes, interfaces and prerequisites.
- [ ] Every retained requirement and alternative has a direct receiving clause.
- [ ] Required reviewed receiving acceptance precedes separate source retirement.
- [ ] Whole completion is not inferred from partial source, CI or plan delivery.
- [ ] Each effect has verified provider state; uncertain writes are not replayed.
- [ ] Existing owners, issue conditions and resource custody remain independent.
- [ ] The actual finite target stops extra cohorts; final journal/gates still apply.
- [ ] Only genuinely resolved own obligations settle; unfinished parent stays open.
- [ ] Static authoring checks are not provider, model, runtime or deployment proof.
