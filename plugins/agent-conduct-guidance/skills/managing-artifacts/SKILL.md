# Managing artifacts

Read the [artifact lifecycle guide](../../docs/artifact-lifecycle.md) for the
current task. It is the single guide for classification, configurable defaults,
custody/disposition, user-delivery receipts and finalization versus cleanup.

1. Classify the output before writing; honor explicit destinations and the
   existing knowledge/machine/storage owner.
2. Resolve a supported location and register custody through its existing owner;
   disclose missing enforcement rather than inventing a claim or path.
3. Perform only the authorized write/delivery/disposition, verify its actual
   outcome and retain the appropriate history.
4. Keep physical cleanup separate from logical completion. Existing scope and
   owner/retention/live-use checks still govern any removal.

For disposable working files, read the [scratch procedure](../using-scratch-space/SKILL.md).
This skill does not install a runtime, enable collection, migrate existing files
or authorize deletion.
