# Finalizing worktrees

Use the selected installation's exact command from the session catalog.
Read the [worktree guide](../worktree/SKILL.md), especially Two-Phase Sign-Off
and outbound obligations, before invoking its completion flow.
The [closeout distinction](../worktree/references/closeout-and-reclamation.md)
owns logical finalization, retained resources and compatibility limits.

Verify the parent objective, required publication/merge gates, artifact
dispositions and child responsibilities. Do not substitute a completed phase
or a clean Git tree for completion. Report logical finality, retained history
and actual checkout removal separately; never reconstruct finalization by hand.
