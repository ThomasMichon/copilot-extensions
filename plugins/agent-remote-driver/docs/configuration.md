# Configuration and discovery state

Agent Remote Driver has **no human-authored configuration file** and no ordinary
repository, knowledge, machine, or repository+machine preference document.
Do not create one by treating a session descriptor as configuration. Node 18+
remains sufficient; configuration discovery does not require Python or Worktrees.

## Invocation selector

[`discovery.mjs`](../extensions/agent-remote-driver/discovery.mjs) owns
`discoveryDir(env = process.env)` and `descriptorPath(sessionId, env)`.
`AGENT_REMOTE_DRIVER_CONFIG_DIR` is an optional string selecting the machine-local
discovery root. A missing or empty value uses the current user's
`.copilot/remote-driver` directory. The reader appends `sessions`, then
`<sessionId>.json`. Native `node:path.join` semantics apply; no expansion of
environment variables or `~` is performed. This environment selector is not a
portable repository preference and has no YAML/JSON aliases, list merge, null
merge, schema migration, or knowledge-binding lookup.

The default environment is sampled on each helper call. The running extension
retains its selected descriptor/endpoint for that instance; changing an external
shell's environment does not relocate a live session. Restart through the
existing instance owner when changing that instance's layout.

## Generated descriptor schema

`buildDescriptor` in the same module produces version-1 JSON:

| Fields | Type and requirement |
|---|---|
| `version` | Integer, generated as `1`; descriptor format, not control protocol. |
| `driverVersion` | String, caller's driver release or `0.1.0-dev1`. |
| `sessionId` | Required nonempty session identifier. |
| `pid` | Required positive integer owner process ID. |
| `host` | Generated string `127.0.0.1`; not an operator bind preference. |
| `port` | Required positive integer selected by the endpoint owner. |
| `token` | Required observer credential, freshly generated by the owner. |
| `controlProtocol`, `instanceId`, `controlToken` | Optional **together**; positive safe integer, nonempty string identity, nonempty administrative credential respectively. Partial declarations fail. |
| `cwd` | Caller working directory or `null`. |
| `startedAt`, `updatedAt` | Caller timestamps or current ISO timestamps; `updatedAt` is independently refreshed. |

These are generated runtime state, not human-authored defaults or authority
overrides. `registry.mjs` owns descriptor admission and stale-instance decisions;
`extension.mjs` owns lifecycle registration and heartbeat. Unknown consumer
fields do not extend the builder's schema. PID alone, a descriptor version, or
file existence does not establish live instance custody.

`writeDescriptorAtomic` writes a mode-0600 same-directory candidate and renames
it over the live path, cleaning its candidate on failure. Keep tokens and local
paths private; do not commit descriptors, copy them into portable configuration,
or print them as examples. Reading a descriptor never grants administrative
control, installation, login, a listener, or permission to replace an instance.

## Validation

The focused `tests/discovery.test.mjs` suite exercises the actual environment
selector, independent descriptor/control versions, complete control metadata,
credential comparison and atomic publication. Existing native lifecycle and
registry suites retain their own process/admission coverage.
