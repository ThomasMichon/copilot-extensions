# Consumer source boundary

[owner: copilot-extensions-harness]

Using this suite does not assign its maintenance. During another product's
task, treat copilot-extensions source as frozen. An error, prerequisite,
Maintainer role, available credential or enabled plugin does not authorize
source edits, issue filing or PR publication.

Diagnose only as needed for the assigned task. Within existing repair
authority, use supported recovery or restore the authentic selected installer's
canonical artifacts. Preserve operator state; never patch package logic or
shipped templates. Report material local changes and verify the original
consumer. Repair approval does not authorize a source contribution.

If recovery is unavailable, report the exact error and affected task step,
offer to file a bug at the established destination, and continue independent
authorized work. Do not start an upstream fix or wait for its review, merge,
promotion or rollout. If no supported path remains, return the precise blocker.

Explicit source-change requests remain valid without a maintainer plugin.
Follow the target repository's own contribution procedure. The optional
copilot-extensions-maintainer package supplies those procedures for ongoing
maintenance; it does not widen the assignment or grant publication authority.
