# SSH legacy bootstrap adoption - 2026-10-24

[Back to the effort](../../README.md). This implements only the SSH bootstrap
row reviewed and merged in #8595, following the fixed recipes in #8585.
The parent and its separate acceptance gates remain open.

## Implementation

The direct legacy session hook now launches the qualified fixed native stamp
or provision action through the packaged standalone foundation and existing
canonical queue. The foundation is declared through SSH's ordinary
`tool.uv.sources` dependency and existing materializer; there is no independent
copier, discovery authority, queue or scheduler.

First stamp uses the hook's own payload. Drift retains the deployment
manifest's exact source path, including native staging's original-source
projection; an unavailable, copied or retained snapshot source is not replaced
with today's installed payload. The native recipe admits only canonical
installed SSH and the default legacy root. SSH's service-less installer and
own value-based no-self-provision control remain unchanged. Pinned reads,
nested custody, managed/malformed publication policy, unsupported sources and
driver skew refuse before queue/installation writes.

The hook's age/PID `reconcile.lock` reaper and inline/background installer are
removed, not retained as a second owner. Its 15-second deadline and exact `{}`
output remain. Stderr identifies a validated finite-supervisor launch and
diagnostic log, explicitly not durable acceptance. The existing ordinary
receipt/result remains authoritative. The independent 10-second companion
registration and 45-second guidance writer are unchanged.

The native test destroys the first hook's caller Job/group during genuinely
Python-free foundation acquisition, observes stamp completion through a full
ordinary receipt, then prepares the first runtime through the already-qualified
fixed recipe rather than an unadopted SSH command. Manifest-selected drift,
exact project/root/source, healthy no-op and installed CLI/distribution/module
origin remain separate assertions. POSIX drift retains the existing metadata
Python prerequisite; first stamp does not add that prerequisite.

All 65 workflow scope controls, edited Python F/E9 lint and all thirteen
