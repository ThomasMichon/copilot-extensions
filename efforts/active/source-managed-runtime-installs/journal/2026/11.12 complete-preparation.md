# Composition delivered and complete preparation integration

The canonical composition increment merged in
[PR #12219](https://github.com/ThomasMichon/copilot-extensions/pull/12219),
commit `da21db6a8b6880103accb689d2436a7dd3fb02ae`, after independent approval
and successful current-head required CI. Together with #12195, this closes S1's
deadline and Git-isolation source increments, not S2's combined replacement
coverage or installed adoption.

The composition adapter uses the existing promotion owner, preserves finalized
Main versions without allocating new ones, and isolates inherited Git selectors.
Version-write targets and changefile paths are admitted before mutation.
The final source selection passed 180 Windows controls with ten explicit skips,
188 Linux controls with two explicit opt-in skips, and the complete 4,827-node
canonical Linux unit packet with zero skips. The eight escaping-symlink cases
ran on Linux; their Windows skips are not equivalent native evidence.

The next integration connects that composition to the existing artifact builder,
one retained toolchain and the existing per-project profile/application emitter.
The profile worker reads every completed selected application back before a
portfolio completion record is written. Prior complete outputs require renewed
source, composition, wheel-content, target, extras, policy, toolchain and
application checks. A selected worker failure propagates; it is not permission
to reconstruct the work as a cache miss. Composition carries the caller's same
deadline into canonical Git, control reads and projection-sync children, with a
cleanup reserve inside that deadline. This adds no alternative builder,
artifact cache, profile solver, publisher or runtime installer.

Focused preparation/reuse controls include real wheel and profile bytes,
unchanged reuse without another builder, and mutation refusals even when a
completion digest has been recomputed. Windows applications retain the exact native dependency-marker environment and
select the standard CPython implementation/version/architecture through UV's
interpreter request, not a cross-target platform override. A marker-sensitive
copied-application control verifies offline locking and execution without
silently expanding the prepared wheel closure.

The broader Windows source-fixture packet also exposed the separate
[extended-executable PowerShell initialization defect](https://github.com/ThomasMichon/copilot-extensions/issues/12253).
An inert comparison reproduced success with ordinary executable spelling and
failure with the extended DOS spelling. That installation-path repair remains
with the next application-installation increment; no passing native installer
lifecycle is claimed here.
