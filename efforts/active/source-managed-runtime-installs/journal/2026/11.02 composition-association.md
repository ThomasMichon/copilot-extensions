## Implementation

- The local install-source adapter consumes the existing canonical
  `local_runtime_promotion.compose` result for a source selection with an exact
  Main seed. It archives the composed Git tree without another materialization,
  preserves official Main package versions, and leaves source refs, index and
  changefiles unchanged. A canonical composition refusal creates no output.

  The existing native-profile snapshot preserves their association. The shared
  project-input consumer validates an additive composition record and detects
  source-seed/tree changes or association removal while real wheels are held.
  Legacy snapshots without that record remain supported.
- Existing portability, staging, artifact-factory and profile owners retain their
  scopes. No competing builder, cache, profile, publisher or unmerged source
  overlay was introduced.
