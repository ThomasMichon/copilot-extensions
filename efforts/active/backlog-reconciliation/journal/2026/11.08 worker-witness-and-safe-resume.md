## Independent retirement evidence

The complete #11512 report identifies a Python 3.12 failure in
`test_lane_admission_retains_original_native_stream_worker`. Static inspection
at
[`793b8d1b5856e93694af6e105f9c6a8726ded03e`](https://github.com/ThomasMichon/copilot-extensions/commit/793b8d1b5856e93694af6e105f9c6a8726ded03e)
read exactly two complete source objects:

| Source | Observation |
|---|---|
| `plugins/agent-dispatch/tests/test_lane_event_retirement.py` | Direct `_handle` accesses appear in the live assertion, final retired assertion and failure cleanup. The matrix deliberately replaces the original worker instance's `is_alive()` with false and wraps its `join()` with a short timeout. |
| `plugins/agent-dispatch/src/agent_dispatch/bridge_event_worker.py` | Capture feature-detects `_handle` and otherwise obtains a platform-native identity witness. Retirement checks and witness release are serialized and successful retirement is retained. |

Replacing the assertions with the poisoned instance's `is_alive()` is not a
valid repair. Raising only the runner version can avoid the reported failure
without demonstrating older-interpreter fallback coverage. An eventual
repair must retain original-worker identity, a running intake record while
the worker is blocked, finished state only after retirement, exact-once
witness release, original exceptions and bounded failure cleanup. Preserve
the legacy/native and poisoned/unpoisoned matrix on supported combinations.

These are source observations, not an executed Python 3.12 reproduction,
passing native controls or a completed fix. The other local-only failures
listed in the original remain separate untriaged leads; no shared cause is
established.
