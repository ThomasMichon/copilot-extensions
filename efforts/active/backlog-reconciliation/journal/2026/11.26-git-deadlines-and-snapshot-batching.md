## #13997: reusable output-aware Git read deadlines

Actual #14033 delivered the original source feature:

- Procutil's stream owner warns after output inactivity without terminating
  a valid quiet operation. Real stdout/stderr bytes, including partial
  lines, reset that warning; non-output activity does not.
- Managed bounded fetch and authenticated remote-head reads use a
  five-minute absolute ceiling and a separate thirty-second output-idle
  warning. Shorter caller/enclosing budgets survive. Credential preparation
  and authentication retries share the original acquisition deadline.
- Existing exact-ref, unknown-versus-absent, destination and publication
  lease checks remain. Publication lock/lifecycle budgets account for the
  longer bounded reads, without replacing the existing process owner.
- The source controls cover quiet completion, byte-driven warning renewal,
  continuing output at absolute expiry, shorter/shared acquisition bounds,
  descendant EOF, cleanup custody and unchanged terminating-inactivity
  behavior.

The inspected paths include `streaming.py`, `owned_process.py`,
`_windows_owned_output.py`, `git_acquisition_budget.py`, `git_fetch.py`,
`git_process.py`, `git_push_transport.py`, `pr_publish.py` and
`publication_deadline.py`, with their focused tests and actor-free
clock/launch-composition controls.

The later reviewed #14059 deliberately changes **explicit foreground
creation with `timeout=None`** to caller-owned completion waiting, bounded
stream capture and preparation-stage heartbeats. It preserves finite
background/default and explicit numeric/enclosing budgets. This is an
intentional mode-specific successor, not evidence that every foreground
fetch still has a five-minute clock. The current delta and its focused
controls retain the original reusable bounded-read machinery.

The proposed disposition is acknowledged `COMPLETED` for this delivered
source request, with #14033 and the explicit #14059 qualification linked.
It does not qualify installed publication or close #14036, whose owner
expressly retains release and the original publication-behavior check.
