## Guiding Intent

A genuine approval or resource boundary should preserve the affected branch,
not stop all useful authorized work. An agent should prepare a decision-ready
proposal, retain the original return state, work another permitted avenue and
revisit the blocked branch when due or when an actual response arrives.

Time and Autopilot are not permission or operator-presence evidence. Existing
scope, all-work holds, privacy/resource limits, review and uncertain-effect
reconciliation remain binding.

## Context

The current agenda is a manual, agent-owned roster with a stack, visit/depth
budgets, queued roots and parked incidental discoveries. A blocked child must
currently remain on the active stack. The read-only helper does not understand
deferred branches or due rechecks.

The existing conduct owner already preserves useful in-charter work and scoped
approvals. Extend it with decision preparation before a blocking question, not a
new presence poller, scheduler, grant broker or automatic effect executor.
