# Explicit originating-session lifetime

[MCP Session Generation Handover](../../README.md)

## Source boundary

The internal adopted caller now accepts the originating session's explicit PID
and native birth before incoming or custody startup. Windows retains a
limited-query/synchronization handle; Linux retains a birth-checked pidfd.
Neither path signals that owner or infers ownership from arbitrary ancestors.
The byte pump observes that pin instead of the ordinary parent watchdog.
Unknown native observations retain the session, with one warning per continuous
outage. Confirmed owner exit closes only this client's custody connection and
uses the existing exact session/upstream settlement.

Ordinary forwarder, CLI and installer selection remain unchanged. The source
does not yet supply ordinary callers' originating-owner acquisition.
Native macOS owner admission is explicitly unsupported rather than guessed.
No new daemon, per-session supervisor, desktop observer or activation mechanism
is introduced.
