# Direct Role-Lifecycle Cohort Receiving

This direct planned-work amendment belongs to the Active
[Linux role fleet effort](README.md) and its OPEN #6030 parent. It preserves
the existing phase plan, checked credits, client/runner subplans and
#5861/#8860 duties. Three lanes share the Fleet Manager lifecycle outcome but
remain distinct: #6424 is client-only installation; #6681 is selected Gateway/
SSH onboarding; #7192 is Actions/ARC configuration and existing-pool adoption.
One lane's source merge, native proof or tracker disposition closes no other.

Only complete actual parent/Active-effort receipt and readback can support
operator-authorized `NOT_PLANNED` subordinate tracking retirement before
implementation. All product work below remains planned and incomplete.
This replaces only administrative OPEN-token instructions for #6424/#6681;
their current source, native, release and resource owners retain their work.
A parent title, link, draft or shared author is not receipt. The #5861-specific
KEEP convention is not a blanket ACK rule for these lanes.
#7192 additionally retains the runner-loadouts Completion boundary: unresolved
transferred work needs actual acceptance by named tracked owners. It remains
OPEN pending that specific disposition, not a new universal ACK ceremony.
