## Existing owners, no advancement

The existing submission-preparation queue owner now has an internal independent
observation path. Its original proposal, bound task relationship and original
allocator-created workspace select the observation. The actual Worktrees record
supplies the native head revision; neither a worker's claimed head nor copied
readiness JSON enters this path. Discovery, metadata and readiness use one
selected command prefix and scrubbed environment.

The [task-obligation reference](../../../../../plugins/agent-dispatch/docs/task-obligations.md#internal-independent-readiness-observation)
owns behavior and limitations. The existing
[separate Worktrees provider contract](../../../../../plugins/agent-worktrees/docs/dispatch-worker-closeout.md#selected-runtime-readiness-transport)
remains unchanged. Prior, missing or rolled-back providers refuse without
finalization fallback, and remote allocations refuse before local launch.
Observation runs outside SQLite, followed by locked rechecks of the exact
proposal, relationship, task/native, allocation, holds and admission.

This closes a bounded consumer prerequisite toward
[submission-retains-worktree-responsibility](../../../../../visions/plugins/agent-dispatch/task-outputs-and-review/README.md#submission-retains-worktree-responsibility)
using the existing
[version-skew-safe service pattern](../../../../../docs/patterns/service-contract-evolution.md).

no queue transition. The retained-preparation completion refusal and persisted
rollback guard remain unchanged.
