## Provider expansion

Worktrees' existing retained-relationship transaction accepts an optional
expected creation nonce. It checks the actual local owner under the record
lock before effects, absence inspection or retirement probes, then rechecks
after external provider I/O. It never manufactures a missing legacy nonce.
Opted-in receipts identify the checked incarnation and executing record-writer
contract; baseline inputs retain their exact prior response shape.

The CLI describes only its executing process. The existing resident rendezvous
separately declares that serving process's serializer contract and relationship
verb version 2. Neither declaration establishes support in every other writer
or permits an incompatible resident to be treated as upgraded.
The [provider reference](../../../../../plugins/agent-worktrees/docs/resource-relationship.md)
owns the wire contract, selection and rollback limits.

The universal current-code serializer preserves lazy nonce backfills and
refuses overwriting a different nonempty incarnation. Existing receiving
allocation restoration remains authoritative before that check. The root-chain
reuse control now actually removes its private predecessor record before
recreation, preserving the orphaned sidecar whose invalidation it tests.
