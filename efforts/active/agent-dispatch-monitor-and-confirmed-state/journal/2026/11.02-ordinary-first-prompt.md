# Explicit ordinary first-prompt admission

The [parent effort](../../README.md) and its
[assignment/startup amendment](../../assignment-startup-amendment.md) remain
Active. This source slice connects explicit ordinary Bridge startup to a
pool-owned claim; it does not switch automatic allocation or publication.

## Source boundary

The existing placement provider accepts the actual `ordinary-bridge` driver
and advertises `ordinary_initial_start_versions: [1]`. Ordinary initial
startup consumes the current assignment and generation, checks its local
execution host, and stores the host and immutable native invocation through
the existing created/resumed-agent owner before any first prompt is sent.
Workspace and agent writes cannot relabel a placed driver.

The pool worker prompt retains coordinator routing, the charter and duplicate
checks but does not acquire another claim or evaluation lease. It directs
independent acceptance through the existing generation/native-fenced start.
Prompt delivery leaves `CLAIMED`; only acceptance resets the startup counters.
Legacy queued startup keeps its existing request and prompt.

The bounded startup descriptor stays CLI-only. Its current exact live-CLI
retry transport does not qualify ACP/native-turn retry. Existing supervision
retains an ordinary pool claim instead of using legacy recovery. No new
daemon, timer, queue table, source registry or native executor is added.

## Validation and remaining work

Contained controls cross the real queue and HTTP placement/storage/start
boundaries plus a synthetic Bridge command boundary. They cover create before
store before send, exact prompt/native persistence, affirmative acceptance,
capacity retention, host/generation/driver/hold refusals, supported legacy
startup, provider rollback, unknown committed storage and original receipt
observation after acceptance. Focused typing and repository contracts remain
part of the source gate; this record does not claim installed/native proof.

Ordinary allocator-instance selection, ACP retry/decision/decline integration,
automatic publication, mixed-cohort adoption, suspended recovery and
own-workspace closeout remain open. No source result authorizes rollout,
physical cleanup, foreign-owner effects or retained-session replacement.
