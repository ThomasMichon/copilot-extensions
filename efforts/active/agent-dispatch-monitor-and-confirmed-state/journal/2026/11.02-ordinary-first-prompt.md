## Source boundary

The existing placement provider accepts the actual `ordinary-bridge` driver
and advertises `ordinary_initial_start_versions: [1]`. Ordinary initial
startup consumes the current assignment and generation, checks its local
execution host, and stores the host and immutable native invocation through
the existing created/resumed-agent owner before any first prompt is sent.
Workspace and agent writes cannot relabel a placed driver.

The pool worker prompt retains coordinator routing, the charter and duplicate
checks but does not acquire another claim or evaluation lease. It directs
independent acceptance through the existing generation/native-fenced start.
Prompt delivery leaves `CLAIMED`; only acceptance resets the startup counters.
Legacy queued startup keeps its existing request and prompt.

The bounded startup descriptor stays CLI-only. Its current exact live-CLI
retry transport does not qualify ACP/native-turn retry. Existing supervision
retains an ordinary pool claim instead of using legacy recovery. No new
daemon, timer, queue table, source registry or native executor is added.
