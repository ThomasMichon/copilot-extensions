## Existing result and audit owner

The queue retains the proposed result and reference in the existing task audit,
bound to its original request, current generation, native owner and protected
workspace assignment. This is custody before observation, not another task state
or obligation ledger. It changes no task state, lease, task owner or claim.
Identical retries read the original proposal; changed output or binding refuses.
Independent holds, execution closure and unconfirmed workspace protection remain
blocking. A bounded blocker update rechecks that same current binding.

The current completion operation refuses prepared tasks before any waiter
retirement, state change or evaluation request. Persisted SQLite guards retain
the refusal under older completion code and protect the original audit request
against replacement or deletion. Unprepared baseline tasks are unchanged.
There is deliberately no success/advance operation or capability advertisement
until Worktrees' nonfinalizing readiness and independent observation exist.
The [provider reference](../../../../../plugins/agent-dispatch/docs/task-obligations.md#internal-submission-preparation)
owns these internal source semantics.
