## Existing Worktrees owners

The internal observer reuses own-worker allocation, native-source and
preservation admission, the actual checkout snapshot, canonical retained
relationship metadata and the existing per-branch merged-content boundary.
It excepts only the exact actual stored own-task relationship during readiness;
normal finalization still blocks the claim. It never saves a worktree record,
finalizes, releases task custody or retires a process.

Every tracked PR receives a fresh authority-bound read rather than credit from
cached merge state. Current clean content, unchanged branch/remote refs and
preserved workspace/head/allocation are rechecked before returning. Missing,
open, unmerged or unobservable facts remain blockers. The no-PR proof is
conservatively ancestry-only, not an untracked squash/patch-equivalence proof.
The [provider reference](../../../../../plugins/agent-worktrees/docs/dispatch-worker-closeout.md#internal-nonfinalizing-readiness)
owns the complete bounded behavior.
