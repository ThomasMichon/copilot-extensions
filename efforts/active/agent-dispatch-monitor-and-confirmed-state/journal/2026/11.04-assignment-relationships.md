## Existing owners, one retained request

The direct claim transaction retains its original workspace, queue, worker,
generation and request on the actual assignment audit event. Allocator
placement retains the requirement on its original reservation without inventing
a worktree. Actual workspace attachment records the creation nonce and actual
worker assignment before protection can be acknowledged. The allocator's
placement actor is never substituted for that worker.

Worktrees reserves and binds the outbound task relationship through its existing
claim ledger, with the original expected creation nonce. Dispatch checks the
ground-owner response, then rechecks its assignment before publishing success.
Interrupted writes retain the same request for reconciliation. Pending
protection blocks execution, including a queue reopened without its writer.
Retained SQLite guards prevent older queue code from forgetting the requirement.

Recovery version 2 extends the existing callback with the original assignment
event and worker, including pending subjects. Completed task responsibility or
confirmed unassignment to unbound queued work permits verified close.
Submission, abandonment, dead-letter status and runner/lease expiry do not.
Cancellation with an absent claim first replays the original reserve and closes
it, retaining a tombstone against a delayed in-flight reserve.

The creation parser preserves the nonce already present in Worktrees' original
output. Required workspace retries always revisit their owner even when stored
project/path facts match. Legacy reservations cannot adopt a new incarnation.
Source capability negotiation and control-authorized reconciliation remain on
the existing coordinator; no second task or obligation ledger is introduced.
The [provider reference](../../../../../plugins/agent-dispatch/docs/task-obligations.md)
owns the detailed wire and compatibility contract.

## Evidence and limits

The source packet exercises direct claim, allocator attachment, lost
reserve/bind replies, replay, cancellation, submission retention, exact
disposition, immutable requirements, raw rollback admission guards, selected
runtime declarations, changed incarnations and preservation-admission refusal.
Current HTTP/client and both MCP surfaces retain the baseline optional form.
Control reconciliation rejects a worker without controller authority; matching
workspace facts cannot skip a pending ground write.

A separate four-case packet uses both real source owners, persisted Worktrees
YAML and its actual finalization obligation gate. Lost reserve or bind replies
keep cleanup blocked. Unassignment or task completion settles the same claim;
submission does not. This is actual source-ledger qualification, not an installed
cohort or native worker lifecycle run.

Two broader validation fixtures needed compatibility corrections. The
Containers configuration reader now wraps a selected peer refusal in its
configuration error; own-activation and maintenance refusals retain their
existing context-error assertions. MCP discovery no longer asserts a stale
total tool count; it checks the actual optional assignment input contract
through the current MCP 2 schema. Neither correction changes production policy.
The first real-ledger assertion also confused a parked resource with a released
obligation; its final assertion now checks verified closure and no unsettled
claim.

The bounded evidence packets are recorded separately rather than represented
as one full-suite pass. The large transport selection exceeded its original
120-second suite budget; the isolated transport packet used 240 seconds within
the same outer budget. Its remaining discovery assertion was corrected and all
26 MCP controls then passed. The broad coupled packet's 415 other controls pass
with 13 platform skips, and the separate four real-ledger controls pass. An
additional 248 non-discovery transport/reservation controls passed in the
isolated transport selection. Every bounded execution verified cleanup.
The final indexed-assignment and event-bound packet passes 103 controls.
All forty admitted typing scopes pass on Linux and Windows; broader runtime
typing remains pending in the existing portfolio.

The first required unit-CI packet refused execution because the admitted
`procutil.py` source digest still described its previous bytes. The single
changed source binding is refreshed without changing nodes, effects, coverage
targets or budget. Required CI and independent review must pass the new head.

Independent review also identified atomic create-and-claim admission,
historical-bound protection, unpinned claim starvation, host-case disposition
and Windows stdin delivery gaps. Qualified atomic create-and-claim now refuses
before insertion. Python and durable version-2 SQLite guards share current
generation/reservation/workspace checks without making retired execution
capacity a prerequisite for retained task responsibility. Unpinned unsupported
workers skip governed tasks, and exact disposition normalizes only the host.
Windows stdin uses the existing owned process/Job capture with concurrent pipe
workers and one execution/cleanup budget.

The corrected queue packet passes 215 controls. After adding the retired-slot
submission case, the final integrated assignment/callback/capture packet passes
212 controls with 13 platform skips. Windows-shaped pipe controls run on Linux
and verify all three workers join; they do not establish native Windows
qualification. All forty admitted typing scopes again pass on both configured
platforms. These packets remain separate from required CI and fresh review.

This closes source integration work toward the reviewed task-responsibility
intent without extending that intent. Existing service-contract evolution and
owner/custody patterns apply. Ordinary coordinator construction still has no
qualified relationship writer: participating-writer admission, caller/cohort
activation, installed/native qualification, readiness, same-conversation
rejection and non-circular decline remain open. No runtime is updated or
restarted and no historical assignment is migrated by this source packet.
