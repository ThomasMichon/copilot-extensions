against the reviewed local-first amendment. The target-oriented shared selector

target authority. Weakening that selector globally would conflate current
execution observations with a requested remote or stored owner.

configured-binding observations and returns immutable naming facts without
requiring enrollment in the optional map. The canonical library source suite
passes 700 cases, including the new Windows/WSL/Linux map matrix, literal
platform-like hostnames, legacy projection, explicit conflict, ambiguity and
