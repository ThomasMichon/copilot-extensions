## Independent review correction

Independent source review found that the shared command and generation-boundary
helpers call `pump()`, while the newly extracted process binding did not provide
that interface. An admitted process worker would fail before reading its run
command. The initial worker controls mocked past `command()`, so they did not
exercise this missing edge.

The process binding now implements the shared polling interface without GUI
dispatch: it has no desktop event queue. This is its deliberate concrete backend,
not recovery from a failed GUI operation. The desktop subclass keeps its actual
bounded message pump. Shared command helpers use the common process interface.

Twelve additional actor-free controls execute the real pipe/framing/correlation,
generation-boundary and deadline helpers, run the real admitted worker handshake
through to the pytest boundary and exact parent-handle closure, and execute the
desktop dispatch override with native actors substituted. The complete affected
group passes 240 controls. Native Windows execution and the separate actual
visibility/focus, construction and lifetime matrices remain unperformed.
