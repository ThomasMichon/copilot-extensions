- The fresh single-attempt Windows qualification returned failure before
  calibration admission: the observer recorded a foreground window absent from
  its simultaneous visible-window enumeration. Both hooks closed and the
  original Job drained, but no calibration control, SDK worker or any of the
  44 required cases ran. This is negative evidence, not current SDK acceptance.
  The invocation is used; unused visible-control permission does not authorize
  replay. No observer weakening, automatic retry or installed change followed.
- Source review also identified two caller regressions outside the SDK's narrow
  frozen closure: bypassing legacy staging had also bypassed the PowerShell
  installer watchdog, and ordinary release payloads could change across a
  provisioning-lock wait without source-runtime metadata detecting it.
- The source repair retains a compiler-free caller-owned whole-tree watchdog
  for PowerShell cell/slot actions, without allocating a legacy staging root.
  It preserves the 480-second default, requires positive override deadlines and
  bounds each captured UTF-8 stream to 16 MiB. Both adapters bind normal package
  identity and the complete selected assembly before lock waits, carry that
  expectation through the recursive transaction, and validate copied bytes
  before publishing a snapshot. Publication sidecars remain separately owned.
- Twelve actor-free controls pass. A separate bounded Linux packet passes all
  34 selected cases, including real held-lock replacement, PowerShell deadline,
  copied-byte rejection, original process-group descendant retirement and the
  existing complete-transaction serialization controls. These are not Windows
  Job/desktop proof. The install contract passes for all thirteen adopters.
- Required source publication, fresh independent review and current native
  acceptance remain open. Another native invocation requires a new explicit
  operator decision; this journal grants none. Both parent efforts remain
  Active, with their full Plan and Validation Plan authoritative.
