virtual environments excluded and downloads disabled during lookup. Missing
preparation uses uv's existing installation owner without bin aliases or
Windows registry registration, then repeats the qualified lookup. Windows
RedirectionGuard refusal remains visible rather than selecting ambient Python;
post-install lookup diagnostics are retained.

The contained Windows bootstrap/system-mode/recovery packet passed 73 cases,
with nine POSIX cases skipped. After preserving the final error diagnostic,
all eleven affected selection/error cases passed again. Touched-test Ruff
F/E9, the 13-plugin installation contract, effort structure and whitespace
checks passed. The subprocess fixtures exercise the real bootstrap protocol
with synthetic uv/source inputs, not an actual fresh managed-Python download.
Actual toolchain acquisition and unsupported local POSIX/live receiving lanes
remain separate qualification; this source work performs no installed rollout.
