# Bounded output groups and stable short-canvas navigation

Parent: [complete effort](../../README.md).
Admitted scope: [output-presentation amendment](../../sidecar-output-presentation.md).

## Source implementation

The selected Bridge codec gives only recognized native message/thought
occurrences a typed internal output kind. The wire action, version, native
entries and hashes remain unchanged. Exact reported subagent IDs may attribute
output; missing/invalid identity keeps the reporter lane. Unknown native kinds,
including literal output-looking titles, remain separate diagnostics.

The virtual layout partitions adjacent same-source/generation/reported-actor
output into groups of at most 64 loaded records. Sixteen groups may be open,
with an explicit exhaustion result; individual raw rows retain the existing
bounded detail expansion. Groups are presentation, not new events or statistics.
No raw record, hash, position, source qualification or live/history fence is
removed. Render/reflow adds no JSON parsing, source scan, process or transport.

Visible selection distinguishes a group header from its first raw record.
Loaded-member aliases retain header and logical-row navigation when groups
extend, split or merge. At most two tracked viewport/selection aliases follow a
surviving group if its old representative is evicted; no old event ledger is
retained for this purpose.

History remains explicitly one page per Older/upward demand, with repeat to
continue and hide to cancel. Incoming output cannot replenish a fill budget.
A short browsing canvas can retain blank space below its anchor instead of
forcing bottom padding. Full-app comparisons exposed a related resize clamp
being mistaken for user scrolling; an obsolete scroll range no longer disables
live-following or requests history.

## Validation

- 108 selected source checks passed in the hardened offline test container:
  layout, widget, actual Bridge codec, DTO contract and all 14 SVG comparisons.
- The actual EventLog/semantic-frame/codec/widget fixture uses one tool start,
  40 native message/thought chunks and a turn completion. Its byte-bounded
  latest page becomes two overview blocks; one explicit older page retains all
  42 source records as three blocks, including the preceding tool occurrence.
  Raw content/proofs, independent live position, detail inspection, cancellation,
  source loss, focus and ordinary/narrow anchor controls remain asserted.
- Interleaved actors, meaningful work, requests, compaction, unknown native kinds
  and literal lookalikes do not merge. Mixed-provider insertion and generation
  replacement exercise group split/merge. Eviction follows a surviving group,
  while the immutable proof map retains the removed record.
- A 5,000-record output window yields 79 bounded groups. Unchanged reflow
  requires zero new heading wraps; one append/eviction stays within three.
  Only the requested 12 rows materialize in the work-count control.
- Two new full-app synthetic comparisons show 46 records as eight blocks,
  with two separate 20-record groups and a visible unknown diagnostic.
  The existing narrow/fault baselines change only for corrected live
  selection/tail geometry; the other ten baselines remain unchanged.
  The new and affected SVG cells/geometry and offline rasterized captures were
  inspected. These are source renders, not installed/native pixels.

Required CI and current-head independent review/merge remain the delivery gate.
The complete parent, original contracts, accumulated tool statistics, native
latency, installed rollout and manual acceptance remain open independently.

## Review correction

The expand, browse-to-header, collapse, Follow-live sequence needs a fresh
layout, not just scrolling: browsing deliberately permits short-canvas padding
that differs from live bottom alignment. Ordinary and narrow actual-source
regressions both failed with retained zero padding before the correction.
Follow live now reflows under its live policy, restoring bottom alignment and
selection in the same action rather than waiting for another source update.
