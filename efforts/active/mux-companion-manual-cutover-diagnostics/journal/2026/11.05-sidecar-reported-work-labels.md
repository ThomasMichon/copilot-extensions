## Confirmed source gap

The real selected-session codec still produced `Bridge session: <native_kind>`
for every occurrence. A synthetic demonstration could therefore show readable
work labels that the actual source path never supplied. Bridge's native
subagent translator already emits reported names, but its bounded semantic
projection omitted them. Existing tool titles reached the projection but not
the normalized summary.

The bounded correction retains optional reported agent name/display-name
fields in the existing extensible details object. It excludes task
descriptions, raw inputs, transcripts and unneeded model metadata. Invalid
types and values over 512 characters retain explicit omission.

Manager uses closed known-event labels with a reported tool title or agent
display name/name where available. Collapsed labels are bounded to 160
characters with explicit truncation; source details and native kinds retain
their existing bounded Evidence path. Unknown native kinds remain diagnostic,
not inferred work or input events. Missing older-provider fields use a generic
occurrence label, never a guessed task description.
