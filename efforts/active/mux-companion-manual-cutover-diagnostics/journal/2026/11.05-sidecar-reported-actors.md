## Confirmed gap and bounded correction

The selected-session codec assigned every occurrence to its Bridge reporter,
even when the owning projection carried an exact reported subagent ID.
Readable labels alone therefore left distinct reported contributions on one
track.

Known lifecycle/tool occurrences now use a reported subagent actor only when
their explicit source ID satisfies the normalized identity bounds. The root
reporter and subagents use separate source-scoped namespaces, so an agent ID
equal to the Bridge session ID does not collide. Equal display names do not
merge distinct IDs. Missing/invalid identity or an unknown native event keeps
the reporter actor; names and parent tool-call text never mint identities.

Literal bounded display-label extraction is shared with the existing summary
path. Raw source identity, native event kind, positions, hashes and Evidence
remain unchanged. This is Manager-only normalization; no provider/wire,
capability, history, callback, polling or runtime policy changes.

Attributed subagent events do not borrow the Bridge reporter's owner-context
parent edge. Their parent tool-call metadata stays in Evidence without an
invented hierarchy target. An occurrence does not establish current running
state, allocation, release or retirement; `reported_state` remains unknown.
