## Requested experience

Show a high-level outline of what happened, what is happening and conditional
next work. Combine a timeline with branch/return tracks for tangents, prerequisites
and actual parallel contributions. An expandable child view shows that actor's
own work and its parent return. The raw feed remains available on demand.

The current accepted bound effort and guiding intent lead the heading. The
initial request is summarized, expandable creation context; it must not become
a stale replacement for the current purpose. Before binding, show the current
explicitly assigned purpose without requiring an effort for every question.

## Rendering and source boundaries

- `●` milestone, `○` returned/reported result, `!` blocker, `◇` unresolved/
  proposed/deferred path, `*` selected actor's current or last-reported position.
- Keep raw clocks/timezone/date boundaries in detail. Display worktree/session
  elapsed, package spans, blocked time and reported job runtime distinctly.
- Derive a visible elapsed ticker from the recorded start and snapshot clock;
  do not require a new state write or agent heartbeat per tick.
- Expand parent agenda → parallel contributions → child agenda → raw evidence.
  Only advertise navigation/actions actually implemented by the selected host.
- Use reported agenda position and owning lifecycle/claim/effort/PR sources.
  Native intent is an optional activity overlay, not phase or acceptance inference.
- Unknown sources remain unknown, not zero or empty. Preserve definitions,
  return points, original budgets, current scope and canonical completion.
- These examples are observers' presentation guidance. They authorize no answers,
  source mutation, new hosting, cutover, head repair, process action or rollout.
