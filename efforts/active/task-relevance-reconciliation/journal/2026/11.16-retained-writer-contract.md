## Adapter boundary

Bridge preserves the original version-1 requirement, saved prefix, request
digest and immutable creation/acquisition facts. The saved prefix remains
historical data, not a recovery execution target. The existing installation
resolver selects a current command, which must advertise the documented
Worktrees record-writer contract and retained-session semantics in the same
installation. Its actual identity is used only for that invocation's receiving
checks; birth provenance is not rewritten.

Acquisition, keyed creation, writer inspection and retained native recovery
share this adapter. Nested continuation keeps the qualified executor rather
than resolving another generation after native preflight. Existing nonce,
workspace, head, native-activation, original-operation and unknown-send
protections remain with their current owners. No schema migration or new
cross-process operation is required.
