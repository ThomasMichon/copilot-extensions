## 2026-11-24 - Review the standalone failure-path exception

- The existing performance rule prohibits per-event child processes. A queued
  standalone Node adapter would require one existing native writer after
  failure, so it is not silently treated as conformant.
- Propose a narrow, review-first exception in the authoritative performance
  pattern: no ordinary-success helper or recurring reporter, no interpreter
  provisioning or collector, existing native privacy/locking custody, fixed
  causes, bounded contained completion, no operation replay, and measured
  Windows/POSIX caller qualification.
- The reason is concrete: Node's standard library cannot implement the shared
  DACL/byte-range-lock/flock contract directly. Assuming permissions or
  substituting uncoordinated append would lose existing guarantees.
- This contract proposal activates no caller. Node adoption, its actual
  performance and compatibility proof, remaining entry families, authorized
  rollout and installed discovery remain open.

## 2026-11-24 - Correct concurrent fork ownership and interval loss

- Review found two real caller defects: overlapping forks could construct two
  replacement writers, and reports from fork callbacks could reach a sealed
  writer after its counters had been checked. The discarded owner then lost
  the only observation of rejected reports.
- Coordinate only parent-process ownership transitions, not the native call or
  user callbacks. The last active fork resumes one settled writer; children
  create fresh coordination instead of acquiring an inherited lock. Explicit
  shutdown prevents a late replacement. A process-scoped loss latch survives
  owner replacement and warns at an explicit owner boundary, never from the
  error callback.
- Both focused native regressions fail on the original caller: overlapping
  replacement construction blocks both returns, and callback losses produce no
  incomplete-evidence warning. After correction, five native Python 3.11 fork
  controls pass, including the two existing controls. The three new programs
  also pass on native Python 3.12, exercising its actual fork/thread behavior.
  Windows' report/lifecycle packet passes sixteen controls with five native
  fork skips. All fixture children settle inside the unchanged supervisor caps.
- Qualification also exposed a fixture issue, not permission to relax storage
  policy: its synthetic home inherited group-write access from the host umask.
  Create that owned fixture directory privately at creation; leave global umask
  and production custody unchanged. Prior runs with that storage refusal do
  not count as evidence for the fork-loss defect.
