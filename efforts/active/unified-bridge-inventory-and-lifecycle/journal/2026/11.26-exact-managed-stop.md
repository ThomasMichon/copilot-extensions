# Exact local managed stop provider

Back to the [canonical effort](../../README.md).

## Provider-first boundary

The next dependency-ordered slice adds an exact local managed stop provider.
It uses the existing lifecycle owner, separate runtime capability and additive
HTTP route. Existing stop/end selectors and callers remain unchanged.
The operation preserves the managed conversation, workspace, history and
pending prompts. It does not resume, force-stop, send a cooperative notice,
reclaim a Host or release durable placement.

The first contained packet passes 68 exact-stop, cooperative, background-work
and Host-reaping controls. All five changed Bridge files and the new actor-free
unit file pass whole-file strict checks for Linux and Windows.
These results precede the live-client correction below.

## Counterexamples and correction

Further self-review identifies two unqualified boundaries. Matching managed
metadata does not establish that the current client's native session matches.
The legacy best-effort teardown can also swallow a cancel or shutdown failure
and then report a stopped status.

Four contained counterexamples fail on that implementation: different client
identity, missing client identity, failed cancel and failed shutdown. Both
teardown-failure cases return HTTP 200 incorrectly. These are source findings,
not observations against retained operator conversations.

The exact path now checks the live client before effects and again after
awaited teardown steps. Failed exact teardown retains the client and reports an
unknown outcome without writing a stopped confirmation. The legacy best-effort
behavior remains unchanged. A further contained case changes the client identity
during Host detachment and requires refusal before cancel or shutdown.
Fresh contained and strict qualification is in progress; the earlier passing
packet is not substituted for the corrected source.

The broader cold-recovery packet remains failed. Its isolated migration
discriminator rejects the existing inbox-consumer schema before stop is called.
That observation does not diagnose the other packet errors, prove a flake or
authorize changing the schema owner's implementation. Required CI remains a
separate gate.

The full effort remains Active. This slice performs no installation, service
replacement, enrollment, retained-message replay or private-worker activation.
