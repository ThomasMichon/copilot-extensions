## Current narrowed leaf

The generation-bearing transition is not qualified. Review exposed a same-second
failed-write/reopen case where distinct generation IDs have identical rounded
journal projections. Baseline metadata cannot supply the missing durable
generation-to-observation association. Rather than add an unreviewed receipt
layer, the implementation is narrowed to retained journal metadata and valid
null rebuild pointers with no generation objects. Positive generation migration
remains open in #13487 and the canonical T3 plan; earlier positive controls below
must not be treated as its acceptance.

The narrowed declaration creates no observations, admissions or generation
bindings. It retains original metadata/events/replay, permits later fresh
terminal-aware load/sync, and refuses every legacy generation while preserving
the original current/noncurrent reader. Configured growth beyond the terminal
binding limit refuses. A request-local cache composes owner expiry and the
original cache/lifecycle checkpoints without changing a shared checkpoint.
Expiry during descriptor or pointer read stops before subsequent objects.

The final packet passes 59 core and 82 service controls, plus whole-file strict
analysis of all eight changed Python files on both analysis targets, under the
unchanged finite resource/deadline envelope with verified cleanup.
Cache-root, generation and pointer enumeration now streams through `os.scandir`
with per-entry lifecycle checks, including the shared publication/rebuild
inventory path. Controls reject eager iteration and refuse on the first invalid
entry without collecting later entries. The earlier expiry and reassignment
comments belonged to the prior generation-import revision; the current leaf
has explicit owner expiry and imports no admission or target binding.
It includes actual CLI/fresh-reader metadata continuity, frozen replay,
newly acquired load/sync, same-second refusal, interrupted adoption/retry,
growth preservation and independent owner/cache authority withdrawal.
The discarded projection-bypass refactor is removed; public generation
validation remains unchanged. This is a safe smaller source leaf, not closure
of retention, provider/installed migration or either parent effort.

The implementation history below retains the original findings and corrections,
not current permission to adopt unassociated generation content.
