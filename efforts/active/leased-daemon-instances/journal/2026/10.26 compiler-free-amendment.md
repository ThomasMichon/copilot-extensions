# Leased Daemon Instances - 2026-10-26

[Back to the effort](../../README.md)

The operator explicitly rejected custom native code and compilation at both
the build/release and device ends, accepting thin shell launchers with shared
standard-library Python for lifetime safety. The earlier prebuilt-C/source-build
choice is superseded, not silently reinterpreted as satisfying this requirement.

The canonical #8403 issue and this same effort were reactivated. The existing
lean-runtime dependency effort coordinates the full
[compiler-free execution amendment](../../../lean-runtime-dependencies/compiler-free-execution.md);
this effort retains the shared daemon-instance replacement rather than creating
a competing registry, supervisor or ownership protocol.

Source inventory found one canonical Linux C helper and fifteen distributed
copies, package/release compilation and embedded Windows compilation/code
emission. Ordinary assembly loading is a separate operation. Pre-Python
bootstrap and strict Windows process/Job contracts remain design and native
qualification gates, not assumptions about interpreter availability.

This entry records a proposed intent/plan amendment only. No implementation,
new compiler invocation, installed-code change, process retirement or rollout
is authorized by it. Earlier compiled-helper test results remain historical.
